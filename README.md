# Efrem-Free-Optimizer
Windows 10/11 optimization toolkit built with C++20 and Qt 6. Features system tweaks, per-game process tuning, CPU monitoring, power settings, and selective rollback.
Efrem Optimizer

Efrem Optimizer is a Windows 10/11 x64 tuning toolkit built with C++20 and Qt 6. It brings system tweaks, per-game process settings, CPU monitoring, and power management together in one interface.

Features

Selectively apply and roll back system tweaks.

Preview commands before applying batch changes.

Configure CPU and memory priorities, process and thread QoS, CPU limits, and timer resolution for games.

Manage running processes and Turbo Boost settings.

Apply NVIDIA registry tweaks.

Create system restore points and review operation history.

Use a multilingual interface.

Performance

Results depend on your hardware, Windows configuration, and the game. FPS improvements are not guaranteed.

Why I’m sharing this

Originally developed as a commercial project, Efrem Optimizer is now publicly available so others can use it, explore its implementation, and suggest improvements.
